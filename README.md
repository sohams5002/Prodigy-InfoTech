# Prodigy InfoTech - Cyber Security Internship Tasks

Five Python security tools built during my cyber security internship at Prodigy InfoTech. Each task lives in its own folder with a script and a detailed README.

| Task | Tool | What it does |
| --- | --- | --- |
| [PRODIGY_CS_01](PRODIGY_CS_01/) | Caesar Cipher | Encrypts and decrypts text with a user-chosen shift value |
| [PRODIGY_CS_02](PRODIGY_CS_02/) | Image Encryption | Encrypts/decrypts images through pixel-value manipulation with a numeric key |
| [PRODIGY_CS_03](PRODIGY_CS_03/) | Password Complexity Checker | Scores password strength and gives feedback and security tips |
| [PRODIGY_CS_04](PRODIGY_CS_04/) | Simple Keylogger | Logs keystrokes with timestamps - educational only, requires user consent |
| [PRODIGY_CS_05](PRODIGY_CS_05/) | Network Packet Analyzer | Captures and analyses TCP packets (IPs, ports, protocol, payload) and logs results - educational only, requires user consent |

The keylogger and packet analyzer are built for learning, include ethical-use disclaimers, and only run after the user accepts them.
